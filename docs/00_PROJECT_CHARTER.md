## 1. 最终目标

构建一个面向智慧工地场景的企业级 PPE 违规检测与智能告警平台。

系统以 YOLO11 为核心视觉检测模型，完成数据工程、模型训练、模型评估、
图片/视频/实时流推理、人员跟踪、Person-PPE 关联、Helmet/Vest 合规分析、
多帧时序违规确认、违规事件管理、SQLite 持久化、截图留证、TTS 告警、
Streamlit Web 平台、历史查询、数据大屏、LLM 智能分析报告及基础 Agent
能力。

项目重点不是单纯提高 mAP，而是形成：

```text
数据
-> 训练
-> 评估
-> 推理
-> 人员关联
-> 规则判断
-> 事件管理
-> 告警
-> 留证
-> 查询
-> 分析
```

的完整工程闭环。

## 4. 明确不属于 V1 MUST

以下范围 LOCKED：

- Safety Harness
- Smoking Detection
- 人脸识别
- 多摄像头跨镜 Re-ID
- 手机 APP
- 云端分布式部署
- 自研 YOLO 网络
- TensorRT
- 外部付费短信服务

这些能力只有得到用户明确批准并记录 ADR 后才允许升级为 MUST。不得用本地
视频替代 RTSP，不得用单帧判断替代多帧确认，也不得用模板结果替代已承诺的
LLM 能力或真实业务能力。
