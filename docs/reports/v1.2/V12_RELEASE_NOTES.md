# ODPlatform-PPE V1.2.0

## 新增与优化

- Vue3离线智能检测工作台：图片/MP4安全上传、任务队列、取消、历史与产物下载。
- 原尺寸图片标注、MP4逐帧检测与H.264导出、时序违规事件分析及关键双图证据。
- 实时监控输入校验、滚动最新事件及真实通道投递回执。
- 固定事件类型短音频缓存与独立播放线程，避免播报阻塞检测、隔离会话冷却。
- 安全助手读取已保存事件，支持筛选、中文事件卡片、证据放大和有依据的解读；不开放任何写入权限。
- 前端/API版本统一1.2.0，旧Streamlit入口保留。

## 验证

前端37项、独立API/业务联合134项通过，构建通过。指定真实MP4两次各570帧完成，缓存语音全部投递成功且播报期间检测继续推进；真实Provider事件引用和图片核验通过；助手1366/1920窗口及证据放大通过。冻结业务全量820项通过，13个独立API文件因冻结环境未安装FastAPI而跳过，不计为通过；详细范围见发布检查报告。
