## 问题与修复

| 问题 | 修复 |
|---|---|
| 服务停止导致无法访问 | 恢复本地 API；保留启动脚本 |
| 历史事件不在第一页时抽屉不开 | 监听路由 ID 直接请求详情；支持同页 query 更新，列表刷新不再反复打开抽屉 |
| 证据翻页仍保留链接原事件 | 初始进入时处理链接，翻页按当前列表选择；筛选归第一页；快速选择采用请求序号防止旧响应覆盖 |
| AI 前端15秒先于Provider超时 | 报告/助手独立180秒客户端等待，普通请求仍15秒；明确Loading和中文超时提示，未改变Provider边界 |
| 生成期间日期可变导致结果误标 | 生成期间锁定日期，日期变化清空旧报告并更新统计 |
| 报告快照与最新统计不同 | 右侧标记“当前范围最新统计”及独立查询含义，正文保留原校验快照 |
| Provider部分英文 | 对已识别句型作确定性中文展示，保留数量、时间、引用；未知句型保留原文，不另调用未经校验的翻译模型 |
| 今日问题实际查全历史 / 中文快捷问法不稳定 | 前端发送本地当天起止UTC时间并显示范围；API仅规范化四个固定快捷问题，自由输入保留原意，经原受控Agent执行 |
| 原无Provider路径会将任意中文改为统计 | 删除泛化子串改写，拒绝类请求交由原权限边界，测试确认 refused/FORBIDDEN_REQUEST |
| 告警入口待处理计数滞后 | 路由变化及事件处理后刷新统计 |
| 预览图片断开无明确提示 | 图像error提示连接中断，提供仅重连预览的按钮；开始/停止加忙碌防重复保护 |
| SHA复制失败无提示 | 捕获失败并提供手动复制提示 |
